Phylogen

Python, Flask, DEAP

An evolution simulator. Species with heritable traits (camouflage, metabolism, defense, senses) live on a habitat grid across six biomes. A DEAP genetic algorithm handles crossover, mutation, elitism, and roulette selection, alongside fecundity, immigration, and predation.

Congressional App Challenge

EqualEyes

JavaScript, WebGL, Web Audio API

A browser disability simulator I built with Hazel Vail. It runs real-time WebGL filters on your webcam to show four types of color blindness and dyslexia, and routes your mic through the Web Audio API to simulate hearing loss in one ear, so people can feel what these are like instead of just reading about them.

Heads up: the color blindness filters don't work in Firefox because of how it handles WebGL. Use Chrome or Safari for those.

A desktop text editor for macOS that opens, edits, and saves .txt and .docx files. Editing runs on Quill, Word documents (text, tables, and images) come in through mammoth.js, and they're written back out with html-to-docx.
